# 지인 지도 (Friend Map)

지인들이 근무하는 회사 위치를 지도 위에서 한눈에 확인하는 웹앱입니다. 내 현재 위치를 누르면 주변에 어떤 지인이 근무하는지 바로 보이고, 마커를 클릭하면 성명·부서·직책·전화번호·이메일·주소가 표시됩니다. 한국뿐 아니라 전 세계 주소를 지원합니다.

## 기술 구성

| 항목 | 사용 기술 |
|------|-----------|
| 지도 | Leaflet + OpenStreetMap (무료, API 키 불필요, 전 세계 지원) |
| 마커 묶음 | Leaflet.markercluster (수천 개 마커도 부드럽게) |
| 주소 → 좌표 변환 | Nominatim (OpenStreetMap 지오코딩) |
| 엑셀 입출력 | SheetJS |
| 저장소 | 브라우저 localStorage |
| 빌드 도구 | 없음 (순수 ES 모듈) |

## 폴더 구조

```
index.html          화면 구조
style.css           디자인
js/store.js         데이터 상태 · localStorage · CRUD (DOM 없음)
js/geocode.js       Nominatim 지오코딩 (DOM 없음)
js/excel.js         엑셀 가져오기 · 내보내기 · 양식
js/map.js           Leaflet 지도 · 마커 · 클러스터링
js/app.js           화면 조작 (유일하게 DOM을 다루는 파일)
server.ps1          로컬 실행용 미니 서버
```

`store.js` · `geocode.js` · `excel.js`는 화면 코드와 완전히 분리되어 있어, 나중에 React로 옮길 때 거의 그대로 재사용할 수 있습니다. 자세한 내용은 [REACT-MIGRATION.md](REACT-MIGRATION.md)를 참고하세요.

## 로컬에서 실행하기

`지인지도 실행.bat`을 더블클릭하면 미니 서버가 뜨고 브라우저에서 `http://localhost:8090`이 열립니다.

브라우저의 위치 기능과 ES 모듈은 보안 정책상 `file://`에서 동작하지 않기 때문에, 파일을 직접 여는 대신 이 서버를 사용해야 합니다.

## 개인정보 보호

이 저장소에는 **연락처 데이터가 포함되어 있지 않습니다.**

- 지인 정보는 사용하는 기기의 브라우저에만 저장되며 서버로 전송되지 않습니다.
- `data/` 폴더, `*.csv`, `*.xlsx` 파일은 `.gitignore`로 제외되어 있습니다.
- 배포 워크플로는 배포 대상 파일을 화이트리스트로 지정하고, 개인정보 파일이 저장소에서 발견되면 배포를 중단합니다.
- 주소를 좌표로 변환할 때 외부(Nominatim)로 전송되는 값은 **주소 문자열뿐이며**, 이름·전화번호·이메일은 전송되지 않습니다.
